# Projeto cozinha
## Sobre o projeto
Sistema desenvolvido com o objetivo de automatizar e facilitar atividades do refeitório da escola SESI de Tatuí.

## MVP
* Cadastrar cardápio
* Atualizar estoque
*Cadastrar alimentos
* Registrar presença

## Tecnologias utilizadas

* PHP
* Laravel
* MySQL
* Bootstrap
* Git
* GitHub

## Funcionalidades

* Tela de Login
* Tela de Cadastro
* Validação de usuário
* Tela de cadastro de cardápio
* Tela de visualização de cardápio
* Tela de gerenciamento de presença
* Tela de gerenciamento do estoque
* Tela de gerenciamento de dicas

## Como executar o projeto

* Clonar repositório:
git clone https://github.com/seu-usuario/app-mobile

* Acessar pasta:
cd projeto_cozinha

* Instalar dependências:
npm install

* Executar as migrations:
php artisan migrate

* Iniciar a aplicação:
php artisan serve

## 🔌 Integração com API

Endpoints utilizados:

* POST /login
* POST /register
* GET /user
